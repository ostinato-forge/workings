# Learner pilot

Status: Not run. No learner results or cost savings have been measured.

## Participants and task

Use five people who use AI assistants and can read simple conditions, loops, and
objects, but have not built an agent loop. Record whether each person meets these
prerequisites. Participation is a user-organized step.

Start each person in a fresh browser profile and open the tool-using agent lesson.
Let them use the normal controls. Do not coach during the independent challenge.
Record requested help rather than hiding it.

The proposed target is four of five people completing the fresh challenge within
ten minutes without hints or solution reveal. Confirm the target before collecting
observations. A small pilot informs revision; it does not establish an effectiveness
rate for a wider population.
